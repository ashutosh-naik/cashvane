# \# Cashvane

# 

# Multi-tenant finance ops platform with an AI cash-flow copilot.

# 

# \*\*Live API:\*\* https://cashvane.onrender.com

# 

# \## Tech Stack

# Java 21 · Spring Boot 3 · PostgreSQL (Neon) · JWT Auth · Docker · Render

# 

# \## Features

# \- Multi-tenant signup/login with JWT authentication

# \- Role-based access control (Admin/Editor/Viewer)

# \- Client, invoice (with line items \& auto-calculated tax/totals), and expense management

# \- Live financial dashboard

# \- Full tenant isolation enforced at the API layer
